## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 操作介面與返回工具箱入口 |
| `app.css` | 來源的版面、按鈕與球場元件樣式 |
| `court.css` | 側邊看場的球場幾何布局 |
| `theme.css` | 個人站配色對應、隊伍與發接球分色 |
| `mobile.css` | 手機四分頁、頁首、底部導覽、主要操作列、觸控尺寸與安全區域 |
| `engine.js` | 分組、服務站位、計分、復原與資料驗證 |
| `app.js` | 名單、設定、畫面、儲存與匯出事件 |
| `mobile-app.js` | 手機切頁、焦點、導覽狀態，以及手機／桌機之間的操作按鈕搬移 |
| `icons.js` | Bootstrap Icons 1.13.1 本機圖示白名單與同頁 SVG 圖示集 |
| `vendor/bootstrap.css` | 來源已使用的 Bootstrap 5.3.3，保留 MIT 授權標示 |
| `vendor/icons/` | Bootstrap Icons 1.13.1 原始 SVG、MIT 授權及 `SOURCE.md` 來源與檔案雜湊 |

從原單一 HTML 抽出資源後，仍使用本機 CSS 與一般 script，不需安裝套件或使用 CDN。離線使用時，請保留整份個人網站資料夾，工具還會讀取共用的 `dist/assets/theme.css` 與網站圖示。

## 配色同步

個人站與羽球工具共同讀取 `dist/assets/theme.css`。全站的背景、文字、深藍按鈕、青色與淡紫色系，優先在這裡修改。

羽球專屬的 A／B 隊、球場、發球與接球顏色，在工具的 `theme.css` 調整。A 方使用藍色、B 方使用紫色；發球與接球另用底色、邊框及文字辨識。既有球場幾何不以換色方式改動。

## 手機介面與共用內容

`767.98px` 以下改用「球場、球友、設定、紀錄」四個分頁；桌機仍顯示完整工作區。這是同一頁面的兩種呈現方式，不是兩套工具：名單、設定、球場與紀錄都共用同一份頁面結構及比賽狀態。

- `index.html`：以 `data-mobile-panel` 標記各面板，底部導覽與完成按鈕用 `data-mobile-go` 指定目的頁。
- `mobile.css`：依 `body[data-mobile-screen]` 控制面板顯示，處理固定頁首、底部導覽、主要操作列、裝置安全區與較大的加分按鈕。放大球場時隱藏手機導覽與操作列，列印時移除固定控制項。
- `mobile-app.js`：切換頁名、選中狀態、焦點與人數提示；離開設定頁前先驗證輸入，進入名單或設定時維持內容展開。
- 「安排下一輪」、「匯出紀錄」與「新活動」都只有一組實際按鈕。手機切換時移到對應位置，回到桌機再搬回；不要額外複製按鈕或重複綁定事件。

修改斷點時，要同步調整 `mobile.css` 與 `mobile-app.js` 的媒體查詢。若新增面板或導覽，請一起更新頁面標記、`mobile-app.js` 的 `screens` 對照與樣式。計分及發接球規則仍在 `engine.js`，不放進手機操作層。

## 本機圖示維護

圖示固定使用 **Bootstrap Icons 1.13.1**，原始 SVG、來源與 MIT 授權保存在 `vendor/icons/`。`icons.js` 將固定白名單中的圖形建立為同頁 SVG 圖示集；執行時不依賴外部字型、CDN 或下載圖示，直接開啟本機檔案也使用同一套圖示。

靜態介面使用 `data-icon="people"` 這類標記；動態產生的按鈕可用 `BadmintonIcons.svg('people')`，或在插入後呼叫 `BadmintonIcons.hydrate()`。只使用白名單中的名稱，不把名單、比分等使用者輸入當作 SVG 內容。新增圖示時，同步保存官方原始檔、來源與授權，並更新 `icons.js` 的白名單。

指令碼載入順序為 `icons.js` → `engine.js` → `app.js` → `mobile-app.js`，避免手機操作層先於比賽介面初始化。

## 資料與功能範圍

複本沿用原有單雙打分組、公平輪替、目標分數、計分、發接球提示、四向看場、換邊、復原、放大、歷史與 CSV 匯出。核心引擎沒有改寫。

複本儲存鍵為 `cwli-badminton-courts-v1`；原工具仍使用 `badminton-courts-v1`。兩者不自動互讀，也沒有將原工具的歷史比分搬入新工具。名單與進度仍只保存在所在網址的瀏覽器。

此次手機介面調整保留複本原有的 `cwli-badminton-courts-v1` 儲存鍵與資料格式。手機／桌機切換只改變呈現與按鈕位置，不新增另一份比賽資料，也不因切頁清空名單或比分。一般介面維護請保留這個儲存鍵；若日後需要變更資料格式，應另行處理舊資料相容性。

直接開啟本機檔案與透過 HTTP 預覽時，瀏覽器可能使用不同儲存範圍；使用中請固定開啟同一個網址，活動結束可匯出 CSV 留存。
