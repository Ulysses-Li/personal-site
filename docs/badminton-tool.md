## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 操作介面與返回工具箱入口 |
| `app.css` | 來源的版面、按鈕與球場元件樣式 |
| `court.css` | 側邊看場的球場幾何布局 |
| `theme.css` | 個人站配色對應、隊伍與發接球分色 |
| `engine.js` | 分組、服務站位、計分、復原與資料驗證 |
| `app.js` | 名單、設定、畫面、儲存與匯出事件 |
| `vendor/bootstrap.css` | 來源已使用的 Bootstrap 5.3.3，保留 MIT 授權標示 |

從原單一 HTML 抽出資源後，仍使用本機 CSS 與一般 script，不需安裝套件或使用 CDN。離線使用時，請保留整份個人網站資料夾，工具還會讀取共用的 `dist/assets/theme.css` 與網站圖示。

## 配色同步

個人站與羽球工具共同讀取 `dist/assets/theme.css`。全站的背景、文字、深藍按鈕、青色與淡紫色系，優先在這裡修改。

羽球專屬的 A／B 隊、球場、發球與接球顏色，在工具的 `theme.css` 調整。A 方使用藍色、B 方使用紫色；發球與接球另用底色、邊框及文字辨識。既有球場幾何不以換色方式改動。

## 資料與功能範圍

複本沿用原有單雙打分組、公平輪替、目標分數、計分、發接球提示、四向看場、換邊、復原、放大、歷史與 CSV 匯出。核心引擎沒有改寫。

複本儲存鍵為 `cwli-badminton-courts-v1`；原工具仍使用 `badminton-courts-v1`。兩者不自動互讀，也沒有將原工具的歷史比分搬入新工具。名單與進度仍只保存在所在網址的瀏覽器。

直接開啟本機檔案與透過 HTTP 預覽時，瀏覽器可能使用不同儲存範圍；使用中請固定開啟同一個網址，活動結束可匯出 CSV 留存。
