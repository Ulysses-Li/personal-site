# FANUC Macro B｜本機指令查找工具

## 開啟位置

- 從個人網站的「小工具」進入 FANUC 查找工具。
- 本機首頁：`dist/tools/fanuc-macro/index.html`，可直接用瀏覽器開啟。
- 透過專案預覽伺服器開啟：在專案根目錄執行 `node scripts/preview.mjs`，再前往 `http://127.0.0.1:5503/tools/fanuc-macro/index.html`。

一般查找、分類、引數對照與收藏使用本機資料，不需要連線。工具只提供指令索引與語法說明，不解譯或執行 NC 程式。

目前有 83 筆條目（43 筆 Macro B、29 筆 G、11 筆 M）及 21 個 G65 引數對照。驗證紀錄見專案根目錄 `QA.md`。

## 檔案職責

以下路徑均相對於 `dist/tools/fanuc-macro/`：

| 檔案 | 維護內容 |
| --- | --- |
| `index.html` | 頁首、搜尋欄、資料類型切換、列表及詳情容器、同頁 SVG 圖示與程式載入順序。 |
| `macro-data.js` | Macro B 條目、原廠來源、G65 引數指定 I 對照表與對照表來源。 |
| `command-data.js` | 銑床／加工中心常用 G、M 指令，以及條目對應的手冊來源。 |
| `app.js` | 搜尋正規化、變數範圍比對、多詞交集、分類、收藏、複製、手機返回與詳情網址。 |
| `app.css` | 本工具的桌機並排版面、手機列表／詳情切換、字級、焦點與減少動態規則。 |
| `../../assets/theme.css` | 個人網站與小工具共用的淺藍、深藍、青色、淡紫、背景與字型變數。 |

載入順序為共用 `theme.css` → 本工具 `app.css`，以及 `macro-data.js` → `command-data.js` → `app.js`。資料使用一般指令碼，不需打包或透過 `fetch()` 讀取，直接開啟本機 HTML 也沿用相同結構。

## 資料檔與引數表

`macro-data.js` 對外提供：

- `window.FANUC_MACRO_ENTRIES`：巨集變數、運算、條件、迴圈與呼叫等條目。
- `window.FANUC_MACRO_SOURCES`：巨集條目的來源清單。
- `window.FANUC_ARGUMENTS`：引數指定 I 的 `{ address, variable }` 對照，例如 X 對應局部變數 `#24`。
- `window.FANUC_ARGUMENT_SOURCE_IDS`：引數對照表所引用的來源 ID。

`command-data.js` 對外提供 `window.FANUC_COMMAND_ENTRIES` 與 `window.FANUC_COMMAND_SOURCES`。介面會合併兩份資料檔建立搜尋索引，不另維護一份結果清單。

引數表只處理指定 I。重複 I／J／K 的指定 II 由相關條目說明，不直接塞進這張單一對照表。P、L 等呼叫控制位址與傳值位址也分開解釋。修改對照時，應核對原廠表格及 `FANUC_ARGUMENT_SOURCE_IDS`，不要按字母順序推算局部變數編號。

## 條目欄位

兩份資料的條目使用同一組欄位：

| 欄位 | 用途與維護方式 |
| --- | --- |
| `id` | 穩定且全域唯一的條目 ID；收藏與詳情網址都引用它。 |
| `type` | `macro`、`gcode` 或 `mcode`，供資料類型篩選使用。 |
| `category` | 繁體中文用途分類，介面會據此建立分類按鈕。 |
| `code` | 顯示的指令、運算字或變數範圍，也是代碼及範圍搜尋的主要依據。 |
| `title`、`summary` | 中文名稱與精簡用途。 |
| `syntax` | 語法結構；待填內容以 `<…>` 標示。 |
| `example` | 自寫的學習片段；有座標、刀號或加工參數時保留佔位，不加入可直接加工的整套程式。 |
| `notes` | 注意事項字串陣列，記錄機型、選配、參數或使用語境差異。 |
| `tags` | 關鍵字字串陣列，可補上中文用途、英文術語及常見查找詞。 |
| `sourceIds` | 來源 ID 陣列，必須能在兩份來源清單中找到。 |

新增條目時，可複製相近物件再修改；同時檢查逗號、欄位與唯一 ID。不要只新增畫面文字卻留下錯誤來源，或為了改標題任意更換既有 `id`。

## 來源與章節定位

來源資料使用 `{ id, title, url, kind, locator, scope }`：

- `id`：與條目 `sourceIds` 或引數表來源 ID 對應，跨兩份來源清單仍須唯一。
- `title`：應包含手冊名稱及規格編號，必要時保留版本。
- `url`：可開啟的 HTTP(S) 原廠資料或原廠內容鏡像連結。
- `kind`：標示「原廠手冊」或「原廠資料」，不能將一般教學文章包裝成原廠依據。
- `locator`：章節、表格及印刷頁碼；若另附 PDF 頁次，需清楚區分兩者。
- `scope`：文件適用機型、年代、鏡像身分，以及此來源能支持的範圍。

條目詳情會呈現其來源連結與章節定位，下方「資料來源與適用範圍」則彙整全部來源。部分連結是第三方保存的原廠手冊；原廠內容與託管網站身分分開標示。

專案保存的是繁體中文短句整理、自寫語法片段與來源連結，沒有把整本手冊下載或複製到工具目錄。開啟來源文件需要網路；維護時以定位連結及精簡摘要補充，避免整段搬入原廠手冊內容。

## 查找與操作方式

- **代碼別名正規化**：G1 與 G01 視為相同代碼，英文大小寫與全形字元也會先正規化。
- **變數範圍查找**：輸入 `#120` 等變數，可比對條目 `code` 中記錄的所屬範圍。
- **多詞交集**：一般條目查找將空格分隔的關鍵字逐一比對，所有詞都符合才保留結果；並與資料類型、用途分類一起作用。
- **搜尋內容**：涵蓋代碼、名稱、摘要、分類、語法、範例、注意事項與標籤。增加同義查找詞時優先補 `tags`，不必複製另一筆條目。
- **引數對照**：切到「引數對照」後，以位址字母或局部變數編號查表，和一般指令結果分開呈現。
- **收藏**：在詳情按星號加入或移除；「我的收藏」可配合搜尋與分類使用。
- **複製**：語法與範例各有複製按鈕。若瀏覽器不允許自動寫入剪貼簿，仍可在程式框選取文字手動複製。
- **手機返回**：窄螢幕選取結果後切到詳情，使用「返回結果」回到原項目；桌機維持結果與詳情並排。手機的「用途分類」先收合，按下才展開；選取分類後自動收合並恢復焦點。

鍵盤可按 `/` 聚焦搜尋；在搜尋欄按 Escape 清除文字，手機閱讀詳情時按 Escape 返回結果。條目使用穩定 ID 作為網址雜湊，方便日後回到同一筆資料。

## 收藏儲存與相容性

收藏使用瀏覽器 `localStorage`，儲存鍵為 `cwli-fanuc-favorites-v1`，內容只包含收藏條目的 ID，不儲存搜尋紀錄或加工程式。

更換瀏覽器、網址、協定或本機開啟方式，可能使用不同儲存範圍；清除瀏覽資料也會移除收藏。瀏覽器無法寫入時，收藏只保留在這次開啟期間，查找功能仍可使用。

維護既有條目時保留 `id` 與儲存鍵。若確有必要更換 ID 或儲存格式，應另行處理舊收藏相容性；不以新增一份重複資料來維持舊收藏。

## 適用範圍

本工具以 Macro B 及銑床／加工中心常用指令為範圍。G90/G91 依加工中心的絕對／增量座標說明；G94/G95 是進給模式；G98/G99 是加工中心固定循環的返回平面，不與車床定義混用。

巨集變數數量、保留範圍、語法及選配可能隨控制器系列、版本與機床設定不同。M03、M06、M08 等常見機能配號另有機床製造商差異；原廠機床表格只能支持該廠所列的實作，不能推為所有 FANUC 機台一致。

新增或修訂技術說明時，先定位對應的原廠章節，將適用條件寫進 `notes` 或來源 `scope`，再維持短句摘要與語法片段的呈現方式。

## 修改後檢查

在專案根目錄執行：

```powershell
node scripts/check-fanuc.mjs
```

再於瀏覽器確認實際搜尋、分類、引數對照、收藏、複製及手機返回；程式與資料檢查不代表現場控制器已驗證。實際執行結果及驗證限制由根目錄 `QA.md` 維護。
