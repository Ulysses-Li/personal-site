# Louis Li｜工程實踐與技術筆記

獨立新版，原本 `C:\Users\Louis\Desktop\links` 保留。本站同時作為個人介紹、作品集、面試履歷與長期技術知識索引。

## 開啟網站

可直接用瀏覽器打開 `dist/index.html`。所有前端資源均在本專案內，不需要 CDN、安裝套件或建置。

本機 HTTP 預覽：在本資料夾執行 `node scripts/preview.mjs`，開啟終端機顯示的網址。Ctrl+C 結束。

## 維護內容

主要編輯 `dist/content.js`：

- `profile`：個人資料與聯絡入口。姓名、職稱、個人簡介與 Email 會套用到頁面；其餘固定文案與頁尾位於 `index.html`。
- `competencies`：四類能力，會同步顯示在首頁與履歷。
- `projects`：每個案例保留背景、方法、證據與下一步；只有可確認的成果才加入。
- `knowledge`：每個主題包含分類、關鍵字與文章段落。現有 8 篇為整理範本，補齊後再移除「整理範本」標示。
- `resume`：個人摘要、技術清單與待補資料。

`dist/styles.css` 管理視覺與列印版；`dist/app.js` 管理導覽、案例詳情、知識搜尋與分類。

## 內容與儲存範圍

第一版為靜態展示網站。瀏覽器搜尋不會將輸入送往伺服器。沒有線上編輯器、帳號系統、雲端筆記或私人後台；內容以檔案維護。網站目前預設僅擁有者可看，並不表示前端內建私人筆記保護。未來公開前，應把私人草稿放在分離且經身分驗證的儲存系統。

年資、公司經歷與成效數字尚未提供；頁面以待補狀態呈現。既有外部網站僅沿用原連結，沒有把其功能視為已驗證。履歷目前是能力摘要初版，補齊待確認資料後再用於正式投遞。
